# 站点说明

这是 **doc.legspcpd.top** 文档站点的第一条自述内容，用来验证「写文档 → 部署上线」的完整链路。

## 这个站点是什么

- 基于 **Docusaurus 4.0.0** 构建的静态文档站
- 默认语言为简体中文（`zh-CN`），并提供英文（`en`）版本
- 通过 **GitHub Actions** 自动构建并发布到 **GitHub Pages**

## 本地预览

```bash
pnpm install
pnpm start:website
```

启动后访问 http://localhost:3000 即可实时预览。

## 如何新增一篇文档

1. 在 `website/docs/` 下新建 `.mdx` 文件
2. 在 `website/sidebars.ts` 的 `docs` 数组里挂上它的 `id`
3. 提交并推送到 `main` 分支
4. GitHub Actions 会自动构建并部署，稍候即可在线上看到

> 这就是一篇最小可验证的示例内容。
