# 响应结构与错误码

本页说明所有接口的通用响应字段，以及调用失败时返回的错误码，便于排查问题。

## 公共字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 本次请求的唯一标识。 |
| `object` | string | 返回对象的类型，例如 `chat.completion`。 |
| `created` | integer | 创建时间（Unix 时间戳）。 |
| `usage` | object | token 用量统计。 |

## 错误码

| HTTP 状态码 | 含义 | 处理建议 |
| --- | --- | --- |
| `400` | 请求参数错误 | 检查 `messages`、`model` 等字段格式。 |
| `401` | 鉴权失败 | 确认 `Authorization` 中的 API Key 有效。 |
| `429` | 请求过于频繁 | 降低并发或稍后重试。 |
| `500` | 服务端错误 | 稍后重试，持续出现请联系支持。 |

## 错误响应示例

```json
{
  "error": {
    "message": "Invalid API key provided.",
    "type": "invalid_request_error",
    "code": "invalid_api_key"
  }
}
```

:::warning
`401` 与 `429` 是最常见的两类问题，上线前请务必做好 Key 管理与重试退避。
:::
