# Site Note

This is the first self-describing content of the **doc.legspcpd.top** documentation site, used to verify the full "write docs → deploy" pipeline.

## What is this site

- A static documentation site built with **Docusaurus 4.0.0**
- Default locale is Simplified Chinese (`zh-CN`), with an English (`en`) version
- Built and published to **GitHub Pages** automatically via **GitHub Actions**

## Local preview

```bash
pnpm install
pnpm start:website
```

Then open http://localhost:3000 to preview in real time.

> This is a minimal verifiable example page.
