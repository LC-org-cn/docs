# 更新日志

## 当前版本

- 对齐上游 Cloudreve v4 `4.19.1`
- 运行环境：Cloudflare Workers
- 数据库：Neon serverless Postgres
- 缓存与会话：Workers KV
- 前端：官方前端，随 Worker 一起发布
- 存储：R2 / S3 / OSS / COS / OBS / KS3 / 七牛 / OneDrive / 又拍云，以及从节点本地磁盘

## 说明

本项目不是 Go 编译移植，而是按上游行为用 TypeScript 重写的 Workers 实现。更新日志以对齐的上游版本为准，具体功能与修复请参考对应上游版本的发布说明与迁移指引。

> 部署与配置详见 [Cloudreve-Worker 安装与配置](/)。
